# SMS v1 — 架构

> 版本: 1.0 | 初始 MCP 桥概念验证

## 概述

SMS v1 是最简单的记忆系统：一个 Node.js MCP 服务器，直接读写本地 JSON 文件。无压缩、无去重、无搜索索引。

## 组件

| 组件 | 文件 | 用途 |
|------|------|------|
| MCP 服务器 | `server.js` | 桥接 Claude Code 到本地 JSON 文件 |
| 记忆文件 | JSON | 通过工具手动读写 |

## 限制

- 无自动去重（需手动管理）
- 无压缩（线性增长）
- 无 FTS5 全文搜索
- 所有操作均为手动
